# Computer Vision

The vision system will turn the physical tabletop into a structured game state.

Initial targets:

- board/map alignment
- Operator identification
- Operator position
- Operator facing
- barricades and destructible terrain
- gadgets and tokens
- objectives
- changes between camera frames

The first prototype should deliberately use a small controlled scenario before attempting full-board recognition.
