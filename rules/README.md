# Rules Engine

The rules engine will represent the game state and determine what actions are legal.

It should be deterministic and testable independently of the AI and camera.

Planned concepts:

- Game
- Round
- Phase
- Operator
- Position
- Facing
- Action
- Line of sight
- Movement
- Attack
- Damage
- Gadgets
- Terrain
- Objectives
