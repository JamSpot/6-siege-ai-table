# First Game — Table Setup Sheet

Keep this beside the board while setting up your first **Consulate — Control (Beginner)** game. It is a setup aid, not a replacement for the Mission Guide or rulebook.

**Golden rule:** copy the beginner setup shown in your Mission Guide exactly. Do not combine it with a different map, mission, or a custom deployment.

## 1. Prepare the table

- [ ] Put the **Consulate** board in the middle of the table.
- [ ] Put the round tracker on **0**.
- [ ] Place every obstacle in its matching printed location.
- [ ] Place the Control objective pieces, barricades, and five cameras exactly as shown in the Mission Guide; check camera orientation.
- [ ] For a Control mission, leave the Barbed Wire and Fortified Entryway tokens out of the mission setup unless your selected mission material explicitly says otherwise.
- [ ] Make a general supply for Wound tokens, Located and Stunned markers, Breach standees, overlays, the Drone marker, and other pieces the mission may need.
- [ ] Put the dice and both line-of-sight rulers where you can reach them.

## 2. Prepare both squads

Use the preset beginner squads listed in the [Consulate Control scenario](./first-learning-scenario.html). Do not add Operators or swap the preset for your first learning game.

- [ ] Put each squad's five Operator profiles in that squad's tactical area.
- [ ] Put an **Operator available** Activation token on every profile.
- [ ] Collect each selected Operator's own gadget pieces and Charge cubes; set activatable gadgets to **Ready**.
- [ ] Give each side its Tactical Inventory board, Reroll token, Overwatch markers, Entryway Overwatch tokens, and Leaning standees.
- [ ] The defender secretly allocates **4 Charge cubes** in the Tactical Inventory board's permitted slots.
- [ ] The attacker secretly allocates **6 Charge cubes** in the permitted slots and puts **3 more Charge cubes** in the slots reserved for drones.
- [ ] Reveal the tactical-inventory choices together, then collect the components for the selected gadgets.

Use the exact profile text and permitted slots printed on the boards and cards. Do not invent a gadget effect or move Charge cubes into a slot that is not allowed.

## 3. Copy the beginner deployment

- [ ] Follow the **Starter Zone / beginner deployment** in the Mission Guide, including the positions and orientations shown.
- [ ] Follow that preset's instructions for visible Operators, Hidden Operator tokens, gadgets, and any Entryway Overwatch tokens. Do not add or remove hidden tokens based on memory; use the preset as printed.
- [ ] Check that no space exceeds its area-capacity limit and that every component is in a legal location.
- [ ] Keep the mission's actual Control scoring and victory conditions in force.

The preset is there to remove setup decisions, not to change the rules during play.

## 4. Choose one timing method

Choose before starting and use the same method throughout the game:

**With the companion app**
- [ ] Select **Beginner** speed.

**Without the companion app**
- [ ] Use the official **No App variant**, not the standard timed rules with the timer ignored.
- [ ] Put all **10 Bonus tokens** in the general supply.
- [ ] Apply the variant's Bonus-token rules whenever a challenge is won, including token effects and cleanup.

Keep the [No App table reference](./no-app-quick-reference.html) beside the board if using that variant.

## 5. Final check before Round 1

- [ ] Round tracker is on 0.
- [ ] All five Operators on each side have an available Activation token.
- [ ] Mission components and camera orientations match the Mission Guide.
- [ ] Gadget pieces and Charge cubes are ready.
- [ ] The selected timing method is clear.
- [ ] Both sides can see the current round sequence: **Attacker first activation → Defender first activation → Attacker second activation → Defender second activation → Upkeep**.

During an activation, use the Operator's profile and the rules to check legal actions, action limits, movement, facing, line of sight, challenges, and effects. Resolve each action fully before moving on.

## If you get stuck

Pause and check the rulebook, Mission Guide, or current FAQ/errata. A useful online reference is the [rulebook](https://www.rulespal.com/six-siege/rulebook) and the [published FAQ/errata PDF](https://tesera.ru/images/items/2554783/FAQ_6_Siege_-_The_Board_Game_-_FINAL_200424.pdf). If this sheet conflicts with official material, follow the official material.

Once setup is complete, keep the [First Game Checklist](./first-game-checklist.html) and [First Round — Coaching Card](./first-round-coaching-card.html) nearby. The goal is to finish a game and learn the flow—not to memorise every rule before you begin.
