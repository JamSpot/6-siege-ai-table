## How to use the tutorial

Start with the beginner game, keep the checklist beside the board, and use the session sheet to record questions. The optional mini-drill is supplementary practice, not the official beginner mission.

**Target milestone:** you can set up the beginner game, play through it without needing the rulebook for every basic action, and understand why each move is legal.

The later AI work will use the same scenarios as controlled tests for board-state recognition and the rules engine.

Each lesson will include explanations, worked examples and practical exercises.
