## How to use the tutorial

Work through the lessons with the physical game in front of you. Each lesson should give you something concrete to practise before moving on.

**Target milestone:** you can set up the learning scenario, play through it without needing the rulebook for every basic action, and understand why each move is legal.

The later AI work will use the same scenarios as controlled tests for board-state recognition and the rules engine.

Each lesson will include explanations, worked examples and practical exercises.
