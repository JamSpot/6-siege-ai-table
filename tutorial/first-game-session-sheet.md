# First Game Session Sheet

Use this one-page worksheet beside the board during your first learning game. It is a project aid, not a replacement for the official mission rules.

## Before starting

- [ ] Open the [Consulate Control beginner setup](./first-learning-scenario.md).
- [ ] Set up the map, objective and deployment exactly as the mission material instructs.
- [ ] Put the Operator cards, dice, line-of-sight tool and reference material within reach.
- [ ] Leave the timer off for this learning session.
- [ ] Agree that anyone can pause play to check a rule.

## Before each attack

- [ ] Is the Operator currently allowed to act?
- [ ] Is the action legal?
- [ ] Is the target legal and in range?
- [ ] Has line of sight been checked with the game's tool?
- [ ] Have weapon, cover/protection and other relevant rules been checked?
- [ ] Has the attack result been fully resolved before continuing?

## After the session

1. What rule caused the most interruptions?
2. Which state detail was easiest to forget (position, facing, status, activation, or objective)?
3. What should the next tutorial revision explain more clearly?
