# First Game Checklist

Use this beside the board while learning.

- Set up the beginner Control mission on Consulate.
- Remember the round sequence: Attacker 1, Defender 1, Attacker 2, Defender 2.
- Up to three Operators can be activated in each activation phase.
- An Operator can only be activated once per round.
- An Operator normally has 5 movement points.
- During an activation, an Operator can move and perform two different actions.
- Movement and actions can be interleaved.
- Check line of sight with the game's line-of-sight tool.
- Use the Operator profile card for weapon and special-gadget information.
- Keep the timer off for the first learning game.

## AI-table data we will eventually track

Operator identity, team, board position, facing, damage/health state, activation state, status markers, gadgets and temporary effects.

## Stop point

When you can complete a full learning round using this checklist without needing to relearn the activation sequence, move on to the detailed combat, gadgets and objective lessons.
