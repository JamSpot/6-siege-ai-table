# First Game Checklist

Use this beside the board while learning.

## Before setup

- [ ] Set up the beginner Control mission on Consulate, following the mission material exactly.
- [ ] Choose a timer mode: use the companion app's Beginner setting, or use the rulebook's official No App variant.
- [ ] If using No App, place the 10 Bonus tokens in the general supply and apply the variant's challenge rules. Do not simply ignore the timer while otherwise using standard timed rules.
- [ ] Keep the Operator cards, dice, line-of-sight tool and current rules/FAQ within reach.

## During each round

- [ ] Follow the round sequence: Attacker first activation, Defender first activation, Attacker second activation, Defender second activation, then Upkeep.
- [ ] Activate only Operators allowed by the current phase and their activation state.
- [ ] Check the current rules for how many Operators can be activated in each phase.
- [ ] An Operator can only be activated once per round.
- [ ] A normal Move action spends up to 5 movement points; check the profile and rules before using Run.
- [ ] An activation normally allows one Move action and two other different actions, in any order; check the official rules for exceptions.
- [ ] Movement and actions can be interleaved where the rules allow.
- [ ] Check line of sight with the game's line-of-sight tool.
- [ ] Use the Operator profile card for weapon and special-gadget information.
- [ ] Resolve challenges, protection, wounds and other effects before continuing.

## AI-table data we will eventually track

Operator identity, team, board position, facing, damage/health state, activation state, status markers, gadgets and temporary effects.

## Stop point

When you can complete a full learning round using this checklist without needing to relearn the activation sequence, move on to the detailed combat, gadgets and objective lessons.

**Rule priority:** this checklist is a learning aid, not a replacement for the current rulebook, mission material or FAQ/errata. If they disagree, follow the official material.
