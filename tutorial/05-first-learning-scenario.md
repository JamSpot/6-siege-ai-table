# Supplementary Mini-Drill — Clear the Room

**Project-created practice drill; not an official mission and not a replacement for the beginner setup.**

For your first complete learning game, start with [Consulate Control — Beginner](./first-learning-scenario.md). Use this shorter drill afterwards to practise basic positioning and line-of-sight decisions.

## Purpose

Practise this repeatable decision loop with one Operator per side on a small, uncomplicated part of a core map:

**position → check facing and line of sight → choose a legal action → resolve it → update the board state**

This drill practises basic decisions; it does not create a new win condition.

## Setup

1. Use a small, uncomplicated section of a core map.
2. Choose one Operator for each side and place them according to the official rules for the map and mode being used.
3. Keep the Operator cards, dice, movement tools and line-of-sight tool beside the board.
4. Do not add custom map rules or custom movement costs.
5. Use the selected mode's normal rules for activations, actions and victory conditions.

## Learning mode

Leave the timer off for the first attempt. Resolve every action completely before taking the next one. If a rule is unclear, pause and check the official rulebook, mission material or current FAQ/errata.

## Three practice rounds

### Round 1 — Approach

Practise movement and facing. Before moving, say what position you want to reach and why. After moving, check facing and line of sight again.

### Round 2 — Contact

Before an attack, check that the Operator can act, the action and target are legal, range and line of sight are valid, and the weapon and protection rules have been applied. Resolve the complete result.

### Round 3 — Review the position

Choose actions based on the current board state. Ask whether a different legal position or action would improve your situation. Continue using the selected mode's official rules and victory conditions.

## Stop and review

Stop if the normal victory condition is reached. Otherwise, after three rounds, continue using the mode's rules or reset the drill.

- What rule did I need to look up first?
- Where did I lose track of facing?
- Where did line of sight become difficult?
- Which action created the best position?
- What would I do differently next time?

## AI-table test

At the end of each activation, record the round, active team, Operator, position, facing, stance/status, damage state, objective state, visible opposing Operators and relevant terrain.

The first rules-engine milestone is to turn a recorded state into a list of **legal actions**. The decision layer comes afterwards.

## Next milestone

Once the official beginner game and this optional drill are comfortable at the physical table, turn the recorded board state into a machine-readable format and test it against repeatable positions.
