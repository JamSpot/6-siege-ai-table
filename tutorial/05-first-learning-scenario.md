# First Learning Scenario — Clear the Room

**Project-created training scenario — not an official mission.**

## Goal

Use one Operator per side on a small section of a core map. The Attacker must reach the marked objective and attempt the normal objective procedure. The Defender must prevent completion or win using the normal victory rules.

## Setup

1. Use a small, uncomplicated section of a core map.
2. Deploy one Attacker and one Defender using the normal deployment areas.
3. Mark one objective space.
4. Keep both Operator cards, dice, movement tools and LOS tools beside the board.
5. Do not add custom map rules or custom movement costs.

## Learning mode

For the first attempt, do not use the timer. Use the normal activation structure and resolve every action completely before taking the next one. If a rule is unclear, stop and check the official rules.

## Three-round drill

### Round 1 — Approach

The Attacker practises movement, facing and finding a useful route. The Defender practises holding a position that protects the objective.

### Round 2 — Contact

Before every attack, check: activation, legal action, legal target, LOS, range, protection, weapon information, then resolve the result completely.

### Round 3 — Objective

The Attacker chooses between pushing for the objective and improving position. The Defender chooses between holding the objective and improving defensive position.

## End of the drill

Stop if the normal victory condition is reached. Otherwise, after three rounds either continue using the normal mission rules or reset and repeat the exercise.

## Five-question review

- What rule did I need to look up first?
- Where did I lose track of facing?
- Where did LOS become difficult?
- Which action created the best position?
- What would I do differently next time?

## AI-table test

At the end of each activation, record:

- round;
- active team;
- active Operator;
- position;
- facing;
- stance;
- damage/health state;
- objective state;
- visible opposing Operators;
- relevant terrain.

The first rules-engine milestone is to turn that state into a list of **legal actions**. The decision layer comes afterwards.

## Next milestone

Once this drill works comfortably at the physical table, build the first machine-readable board-state format and test it against the same scenario.
